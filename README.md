# 異世界村育成TRPG

AIとのチャットで村の人たちと相談し、仕組みを作りながら困りごとを解決する教育向けTRPGです。公開版の基本仕様は v0.2 です。

## チャットで遊ぶ

村の困りごとをAIと相談して解決する会話ゲームです。1か月ずつ進み、ゲーム内の3年間を遊びます。正解はひとつではなく、途中で休んだり、考えを変えたりできます。

新しいチャットに次の1行を貼り付けてください。仕様書を読めないAIは、読めたふりをせず、そのことを伝えるよう指示しています。

`この仕様書を読んで、異世界村育成TRPGのGMとして始めてください。最初にゲームを短く説明し、導入と3年後の目標を私と相談してください。URLを読めない場合は、読めないと伝えて止まってください。 https://raw.githubusercontent.com/singtur-lab/village-game/main/docs/spec-v0.2.md`

仕様書: [docs/spec-v0.2.md](docs/spec-v0.2.md)
