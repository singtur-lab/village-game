# 村育てAI — prototype 0.1

AIとの対話で村の方針を決め、月ごとの結果を見ながら育てる、異世界シムシティ型ゲームの試作です。

## 今入っているもの

- `prototype/index.html` — インストール不要で動く単月進行のブラウザー試作
- `docs/GAME_DESIGN_v0.1.md` — ゲームの柱、ターン、状態、AIの役割の初版
- `docs/ORIGINAL_SOURCE_AUDIT.md` — 元リポジトリの確認結果と素材の扱い
- `data/demo_village.json` — 試作専用の架空初期データ
- `data/campaign_baseline_319-12.json` — 遊び込んだ村キャンペーンから、公開向けに整理した引き継ぎデータ

## 起動

`prototype/index.html` をブラウザーで開きます。進行状態はブラウザー内に保存できます。AI接続は未実装で、自由記述欄はプレイヤーの相談・判断を記録する試作機能です。

## 状態

これは遊びの核を検証するプロトタイプです。製品版の仕様確定、AI接続、複数シナリオ、アクセシビリティ、各種ブラウザーでの検証は今後の作業です。

## 出典とライセンス

元作品のREADMEとライセンスは `docs/ORIGINAL_SOURCE_AUDIT.md` に記録しています。この試作には元リポジトリの画像・コード・文章を複製していません。本プロジェクト自身のライセンスは、配布方法と権利確認を終えてから決定します。
