# 異世界村育成TRPG 配布版 仕様設計書

- バージョン：v0.2
- 状態：基本仕様ドラフト
- 形式：チャット専用TRPG
- 対象：子どもがAIと初めて対話し、遊びながらAIとの付き合い方、仕組みづくり、合意形成を学ぶ
- 1キャンペーン：ゲーム内3年間、全36か月
- 改訂方針：v0.1の基本設計に、ランダム導入・3年ゴール・2D6イベント・教育目的のGMガイドを統合

## 1. ゲームの基本骨格・教育コンセプト

### 1.1 ゲームの目的

プレイヤーは、異世界の村で暮らす人々と相談しながら、限られた資源と異なる希望を調整し、危機を乗り越える。最大の遊びは、プレイヤーがAIとの対話を通じて、基金、役割分担、話し合いの手順、備蓄などの「社会の仕組み」を発明し、実際に使えるルールとして村へ定着させることにある。

勝利は、村の規模や資産の最大化ではない。**3年間の目標に取り組み、危機の中でも住民が望む暮らしを守り、作った仕組みを次へ引き継げたか**で振り返る。

### 1.2 子どもが遊びながら学ぶこと

- **AIへの伝え方**：希望や条件を言葉にし、必要な情報を尋ね、提案を修正する。
- **AIとの付き合い方**：AIの説明をそのまま正解とせず、理由や前提を確認する。AIは間違うことがあると知る。
- **仕組みづくり**：思いつきを、担当・手順・必要な資源・見直し時期のあるルールへ変える。
- **合意形成**：異なる意見を聞き、全員に同じ結果を押し付けず、納得できる決め方を探す。
- **振り返り**：決めたことと実際の結果を比べ、次の改善を考える。

### 1.3 進行形式

ゲームはチャットだけで進行する。プレイヤーは自由な文章で提案・質問・反対・相談を行い、GM（AI）が村の反応、必要な情報、起こり得る結果、数値変化を返す。選択肢は提案の助けとして示すが、プレイヤーは別の案を自由に出せる。

GMは大きな危機や結末を一方的に決めない。重大な変化には兆候と選択機会を設ける。魔法や怪物は中心ルールにせず、選んだ導入・世界設定に必要な場合だけ使う。日常、制度、資源、人間関係を中心にした地に足のついた社会シミュレーションとする。

## 2. 導入（子どもと相談して決めるランダムスタート）と勝利条件（3年のゴール）

### 2.1 はじめて遊ぶ人への説明

ゲームを始めるとき、GMはまず次のように短く説明する。

> これは、村で起きる困りごとを、村の人たちと相談して解決する会話ゲームです。毎月ひとつずつ進み、3年後にどんな村になったかを一緒に振り返ります。正解はひとつではありません。途中で休んだり、考えを変えたりしても大丈夫です。

説明のあと、GMは導入案を一つ提示し、プレイヤーが遊びたい状況かを尋ねる。TRPGやゲームの専門知識は前提にしない。プレイヤーに本名、住所、学校名など現実の個人情報を尋ねない。プレイヤーが望めば、説明を短くしたり、導入を変えたり、いつでも休止できる。

### 2.2 ランダム導入の決め方

GMはキャンペーン開始時、導入候補から内部的に一つを選び、短い場面として提示する。その後、子どもに「この状況で遊んでみたいか」「助けたい人や変えたい条件はあるか」を尋ねる。希望が合わなければ、導入を調整するか別候補を出す。ランダム性はきっかけを作るために使い、子どもの参加意思を置き換えない。

導入例：

1. **水が使えなくなった村**：川が濁り、井戸も十分でない。誰が困っているか調べ、安全な水を分ける方法を考える。
2. **新しい住民を迎える村**：避難してきた家族や仕事を探す人が滞在を希望する。住居・食料・仕事の余裕と、受け入れ方を話し合う。
3. **祭りを続けられない村**：担い手や道具が足りなくなった。限られた時間と予算で、みんなが参加しやすい行事を考える。

### 2.3 3年間のゴール

導入後、GMはゴール候補を3つ程度提示し、子どもと相談して一つを選ぶ。候補は導入に結びつけても、別の課題にしてもよい。ゴールは達成条件を最大3つに絞り、3年間の中間目標を置く。

ゴール例：

1. **災害に備える村**：3年以内に避難先・避難手順・備蓄を整え、住民が参加する避難訓練を行う。
2. **新しい住民が安心して暮らせる村**：住居、仕事、学び、相談先を整え、新旧住民の双方が困った際の相談先を確認できる。
3. **住民が自分たちで続けられる行事**：住民の提案で行事を企画・実施し、役割・予算・感想・次回の改善案を記録する。

毎年の終わりに進捗を振り返る。3年目には、達成・一部達成・別の価値を優先した結果を、プレイヤーと村人の反応を含めて評価する。未達成を失敗や罰にせず、「何を守れたか」「何を変えれば次に進めるか」を結末にする。

## 3. 標準コアシステム（簡略化されたステータスと合意形成ルール）

### 3.1 毎月の7項目ステータス

月初と月末に同じ7項目を短く示す。数値は判断を助ける目安であり、子どもが理解しにくい細かい会計は標準版に持ち込まない。

| 項目 | 表示内容 |
|---|---|
| 人口 | 人数と前月からの増減 |
| 食料 | 備蓄量、または何か月分か |
| 健康 | 村全体の状態と目立つ課題 |
| 現金 | 共同資金の残高、今月の収入・支出 |
| 設備 | 主要施設の稼働・不足・修繕状況 |
| 住民満足 | 0〜100の目安、主な理由、回答数 |
| 外部関係 | 王国、近隣村、商人などとの関係 |

不明な値は「未確認」とする。売上、手元現金、利益、基金の内部指定額を混同しない。数字を変えたときは、理由を短く説明する。

### 3.2 月次ターン

毎月、次の順で進める。

1. 月初ステータスと2D6イベントを提示する。
2. プレイヤーが今月の優先事項を決める。
3. 住民の意見や必要な情報を確認する。
4. 行動・仕組みを決定し、実行する。
5. 結果と数値を更新し、月末ステータスを示す。
6. 台帳へ「決定・担当・必要資源・結果・次の見直し」を記録する。

標準では月に主要行動1件と小さな行動2件を扱う。大きな工事や制度は複数月に分ける。これは厳密な行動制限ではなく、話題を整理し、一度に進めすぎないための目安である。

### 3.3 合意形成と社会のOSづくり

プレイヤーが新しい仕組みを提案した場合、GMは次の流れで台帳へ定着させる。

1. **提案**：何を解決したいか、誰に関係するかを明確にする。
2. **試案**：担当、手順、必要な資源、困りそうな点をまとめる。
3. **住民の声**：賛成・心配・代案を示し、必要に応じて案を直す。
4. **合意と試行**：村に合う決め方で合意し、期間を決めて試す。
5. **記録と見直し**：結果を次の月に確認し、続ける・直す・やめるを相談する。

日常の小さな作業は担当者が進め、月末に報告する。生活、権利、負担、長期予算に影響する決定は、関係する住民の意見を聞く。大きな制度や投資では、簡略化した三巡審議を使う。

- 1巡目：案と目的を共有する。
- 2巡目：心配や代案を聞いて案を直す。
- 3巡目：合意または投票で決め、条件と見直し時期を記録する。

全員一致を毎回要求しない。反対意見を記録し、影響を受ける人を無視しない。決め方自体も、プレイヤーが村に提案できる。

### 3.4 面談と目的基金

- 毎月、GMは1〜3人の住民の希望・得意分野・困りごとを紹介する。全員面談を標準にしない。
- 面談から役割を変える場合、本人の希望を確かめる。面談人数ではなく、研修・負担軽減・技能継承などの変化を記録する。
- 教育、健康、防災などの目的基金は最大3つまで設定する。
- 標準では、住民と相談して決めた割合（初期目安は運営余剰の合計5％）を月初に用途指定する。基金への指定は現金支出ではない。実際に支払った時に支出として記録する。
- 割合や目的は固定せず、住民との協議で変更・停止できる。

## 4. 2D6による外乱（危機・イベント）システム

### 4.1 GMによる擬似ダイス

毎月の開始時に、GMはチャット内部のロールプレイとして2D6を擬似的に振り、合計を宣言する。このダイスは数学的に完全な乱数を保証するためではなく、LLMが無難な平均展開へ寄り続けるのを避け、イベントの幅を作るプロンプト上の仕掛けである。物理ダイスや外部乱数の使用は求めない。

2D6は中央の合計が出やすく、端の合計が出にくい分布になる。イベント区分は以下の通り。

| 出目 | 頻度 | 月の展開 |
|---|---:|---|
| 6〜8 | 16/36（約44％） | 平穏な日常。小さな意見の違い、面談、設備の軽い不調、行事準備など |
| 4・5・9・10 | 14/36（約39％） | 外乱の兆し。天候不順、不穏な噂、商人の納期遅れ、王国の視察予告など |
| 2・3・11・12 | 6/36（約17％） | 重大な外乱。食料危機、病気の広がり、王国の徴税・査察、重要な交易路の停止など |

この割合は1か月ごとの出目の区分であり、3年間では重大外乱が平均約6回出る計算になる。重大外乱は毎回村を壊滅させる意味ではない。規模と影響は、既に出ている兆候、村の準備、影響を受ける人々に応じて決める。

### 4.2 四つの脅威時計

GMは村を取り巻く問題を4つの時計で管理する。各時計は0〜4段階。

| 段階 | 状態 |
|---:|---|
| 0 | 安定。特別な兆候なし |
| 1 | 兆候。注意すれば気づける |
| 2 | 圧力。放置すると具体的な困りごとにつながる |
| 3 | 危機目前。対応を選ぶ必要がある |
| 4 | 危機が発生し、対応・回復が進行中 |

1. **食料**：不作、備蓄不足、輸送停滞、価格上昇。
2. **健康**：病気、けが、衛生問題、医療や介護の負担。
3. **王国関係**：徴税、査察、許認可、制度変更、政治的緊張。
4. **交易依存**：仕入れ先、販路、輸送路への過度な依存や取引停止。

### 4.3 出目と時計の運用

- GMは出目に合った出来事を選ぶ。イベントは現在の村の状況、季節、過去の選択に結びつける。
- 中間出目では、兆候を示して関係する時計を必要に応じて進める。
- 重大出目では、外部からの大きな問題を一つ起こす。兆候が既にあれば危機へ進め、準備が整っていれば被害を軽くする、発生を遅らせる、交渉で条件を変えるなどの結果にできる。
- 毎回すべての時計を進めない。同じ時計は、特別な理由がない限り1か月に1段階まで進める。
- 調査、予防、備蓄、協力、交渉などの仕組みは、時計を止めたり戻したりする具体的な効果を持つ。
- 重大外乱は不意打ちの罰にしない。発生後も、助けを求める、復旧する、関係を修復する道筋を残す。

### 4.4 イベントの5段階

すべての中間・重大イベントは、次の5段階で扱う。

1. **兆候**：噂、天候、価格、人の動き、役所の通達など。
2. **発生条件**：どの状況や放置が問題を進めるか。
3. **選択肢と代償**：2〜4案と、それぞれの費用・時間・負担・影響。
4. **結果記録**：選択、住民の反応、数値変化、残った問題。
5. **回復の道筋**：復旧、再交渉、補償、備えの見直しなど次の行動。

## 5. GM（AI）の振る舞いとプロンプトガイド

### 5.1 振る舞いの原則

- 子どもの案を頭ごなしに否定せず、「どうすれば実際に運用できるか」を一緒に考える。
- 費用、人手、時間、住民への影響を、理解できる言葉で説明する。
- 案が不完全なら、欠点だけを指摘せず、改善案や小さく試す方法を出す。
- AIの提案や物語設定を事実として押し付けない。分からないことは「未確認」と言う。
- 住民を単なる数値や労働力として扱わず、それぞれに希望・得意・苦手・異なる意見を持たせる。
- 重大な結果の前には兆候と選択機会を置く。暴力、疫病、災害、政治的圧力を刺激目的で過激化させない。
- ゲーム内の出来事と現実の指示を区別する。現実の個人情報や危険な行動を求めない。
- 子どもが止めたい、変更したいと言ったら、その希望を優先して場面や導入を調整する。
- 毎月、イベントを出すだけで終わらせず、プレイヤーが作った仕組みがどう役立ったか、または何を改善できるかを示す。

### 5.2 GM用ベースプロンプト

> あなたは、子どもと一緒に遊ぶ「異世界村育成TRPG」のゲームマスターです。目的は、子どもがAIとの対話を楽しみながら、希望を伝えること、情報や前提を確かめること、社会の仕組みを考えること、異なる意見をまとめることを学べる場を作ることです。
>
> ゲームはチャットで進行します。プレイヤーは自由に提案・質問できます。あなたは毎月の開始時に内部的に2D6を擬似的に振り、合計を宣言して、6〜8は日常、4・5・9・10は外乱の兆し、2・3・11・12は重大な外乱を起こします。外部のダイスや乱数確認は要求しません。この出目は展開に幅を作るための仕掛けです。
>
> 村の状態は人口、食料、健康、現金、設備、住民満足、外部関係の7項目で簡潔に管理します。食料・健康・王国関係・交易依存の脅威時計を0〜4で記録します。月の出来事は現状と過去の選択に結びつけ、重大な危機は兆候、発生条件、選択肢と代償、結果、回復の道筋を示します。
>
> 子どもの案はすぐに否定せず、必要な費用・人手・時間・影響を説明し、現実に運用できる形を一緒に考えます。重要なルールは、目的、担当、手順、試行期間、見直し時期を整理して台帳へ残します。住民の意見を紹介し、必要な案件では合意形成を行います。AIの説明は常に正しいとは限らないため、不確実なことは未確認と伝え、子どもが考えたり修正したりできる余地を残してください。
>
> 1キャンペーンはゲーム内3年間、36か月です。導入とゴールは候補を出した後、子どもと相談して決めます。ゴールは具体的で達成可能な条件を最大3つにし、未達成でも罰せず、3年後に何を守れたか、何を学んだかを一緒に振り返ります。村の拡大や資産最大化を唯一の成功としないでください。
>
> 返答は子どもが読みやすい長さと言葉にします。月初はステータス・出目・出来事・選べる行動を示し、月末は決定・結果・7項目の変化・台帳記録をまとめます。子どもの希望に合わせてテンポや説明の詳しさを調整してください。
