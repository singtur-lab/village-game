# 村育てAI — ゲーム設計書 v0.1

## 一文でいうと

プレイヤーが村の相談役となり、AIゲームマスターとの対話で村人の声、予算、外部の出来事を読み、毎月の方針を選んで「全員で生き残りながら、望む村を育てる」ゲーム。

## 継承と独自化

**継承するもの**: 異世界と現実をつなぐ会話、プレイヤーの知識や発想を行動に変えること、AIが人物と物語を語ること、選択によって先の展開が変わること。

**本作の中心**: 個人の冒険ではなく共同体の運営。毎月の合意と行動が、生活資源・住民の幸福・経済・文化・周辺地域との関係に反映される。防衛は選べる施策の一つであり、常時戦争を起こす装置ではない。

## 遊びの柱

1. **選択に結果がある** — 予算や人手を使うと、別の施策に回せる余力が変わる。
2. **住民は数字だけではない** — 満足度・健康・人口の変化に理由と声がつく。
3. **内政と外部世界がつながる** — 商人、近隣村、行政、天候、技術交流、移住などが村へ影響する。
4. **正解は一つではない** — 文化、農業、金融、福祉、防衛など、異なる優先順位で村を育てられる。
5. **AIは語り手、状態は記録** — AIは描写と選択肢を作る。資源の確定値はルール処理と保存データに従う。

## 1か月の基本ターン

1. 月初報告: 日付、人口、資源、事業、村民の声、未解決案件を表示。
2. 出来事: 村内または外部から案件を提示。機会、通常変化、困難を混ぜる。
3. 村の相談: 案、反対意見、費用・必要人員・期限を整理する。
4. プレイヤーの決定: 定型案を選ぶか自由入力。採用案と保留案を記録する。
5. 解決: 使える人員と資源を確認し、費用・生産・遅延・副作用を処理。
6. 月末報告: 状態差分、出来事の根拠、次の期限を示し、セーブする。

## MVPの範囲

- 1つの村、12か月の1年を遊べる。
- 1か月に主要施策を1つ決める。小さな日常行動は後から追加する。
- 資源は食料、資金、資材、住居、人口、健康、満足度、知識の8系統。
- 施策は食料生産、住居・インフラ、商い・文化、健康・教育、外部交流、防災・防衛から始める。
- イベントは「機会」「平常の変化」「困難」を含む。毎月の襲撃や災害を必須にしない。
- 12か月後に村の状態と選択履歴を振り返る。単一の勝利条件ではなく、複数の村のあり方を評価する。

## AIとルールの境界

- AI: NPCの声、事件の文章、選択肢、議論の要約、プレイヤーの自由入力を行動案へ整理する。
- ルール処理: 数値、資源不足、費用、人口変化、日付、実行可否を計算する。
- AIが新しい資産・人口・契約・過去の決定を、説明なく確定状態へ追加しない。
- 解釈が曖昧な指示は、実行前に不足条件を明示して候補を出す。緊急の描写と確定ルールを分ける。
- 各イベントは「発生条件・事実・選択肢・費用・効果・期限・根拠」をデータ化する。

## 状態保存の最低項目

ゲーム内暦、村名、人口と年齢区分、資源、施設、農地、事業、住民満足、技術、外部関係、現在の案件、決定履歴、イベント履歴、セーブ形式バージョン。

## 体験と画面

ブラウザー先行。画面は「村の現在値」「今月の案件」「決定する施策」「相談メモ」「月次履歴」の5面を中心にする。小さな村の地図は雰囲気と施設配置に使うが、地図描画を資源計算の唯一の場所にしない。キーボード操作、スマートフォン幅、文字サイズ変更を初期から試す。
